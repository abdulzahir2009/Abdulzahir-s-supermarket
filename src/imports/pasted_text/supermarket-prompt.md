# SUPERMARKET E-COMMERCE WEBSITE — FIGMA MAKE MASTER PROMPT

## 01 — PROJECT OVERVIEW

Design and build a modern, premium supermarket e-commerce website based on the attached brand logo.

The attached logo is the primary visual identity reference for this project. Study the logo carefully and translate its visual language into the website UI.

The overall design concept is:

**“NATURAL FLOW”**

The website should communicate:

* Freshness
* Organic quality
* Natural vitality
* Growth
* Sustainability
* Trust
* Convenience
* Modernity
* Accessibility
* Reliability

The final result should feel like a **real, production-ready supermarket e-commerce platform**, not a generic template or a simple visual concept.

Prioritize usability and conversion while allowing the brand identity to strongly influence the visual design.

---

# 02 — BRAND INTERPRETATION

Use the attached logo as the primary reference for:

* Brand colors
* Shape language
* Visual rhythm
* Organic forms
* Curves
* Movement
* Brand personality
* Overall emotional tone

The logo communicates a combination of:

**Nature + Growth + Trust + Connection + Movement**

The website should therefore combine:

**Organic visual elements + clean e-commerce structure.**

Do NOT simply place the logo on a generic supermarket template.

Instead, make the entire interface feel like an extension of the logo.

The logo's swirling/interlocking visual language should inspire subtle:

* Curves
* Flowing shapes
* Organic containers
* Rounded sections
* Wave transitions
* Decorative lines
* Circular motifs
* Soft background forms

However, do not overuse decorative shapes.

The website must remain clean, professional, easy to navigate, and highly usable.

---

# 03 — CORE DESIGN CONCEPT

## NATURAL FLOW

The website should visually feel as though content is naturally flowing from one section into another.

Avoid a rigid design where every section is a rectangular box.

Instead:

* Use generous whitespace.
* Use large rounded containers.
* Use soft organic curves.
* Use subtle wave transitions between major sections.
* Use curved image masks where appropriate.
* Allow selected imagery to slightly overlap its container.
* Use flowing decorative shapes inspired by the logo.
* Keep the interface structured underneath the organic visual language.

The result should feel:

**Fresh, calm, energetic, trustworthy, premium, and modern.**

# 05 — TYPOGRAPHY

Use a clean, modern sans-serif typography system.

Preferred typography:

### HEADINGS

Montserrat

Use:

* Medium
* SemiBold
* Bold

Headings should feel modern, confident, and friendly.

### BODY

Open Sans, Lato, or another highly legible modern sans-serif.

Use the typography consistently throughout the interface.

Recommended hierarchy:

* Display / Hero: 56–64px
* H1: 44–52px
* H2: 32–40px
* H3: 24–28px
* Body Large: 18px
* Body: 16px
* Small: 14px
* Caption: 12px

Use appropriate responsive scaling on smaller screens.

Do not use decorative script fonts for important content.

If an accent typeface is used, use it extremely sparingly.
